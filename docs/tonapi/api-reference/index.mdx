This section provides complete interactive documentation for all TonAPI REST API endpoints. You can explore endpoints, view request/response schemas, and try out API calls directly from this page.

## Getting Started

All methods are available without authentication, but with a rate limit of 1 request per 4 seconds (0.24 rps).

To authorize your request, you will need a token, which you can obtain from [TonConsole](https://tonconsole.com/). To pass the token in your request, add the Authorization HTTP header with the "Bearer scheme":

```bash
curl \
 -H 'Authorization: Bearer YOUR_TOKEN_HERE' \
 'https://tonapi.io/v2/blockchain/masterchain-head'
```

## Base URLs

TonAPI provides two base endpoints depending on the target network:

- **Mainnet**: `https://tonapi.io`
- **Testnet**: `https://testnet.tonapi.io`

## Rate Limits

The rate limits for all of your issued tokens are the same and match the plan you have. The rate limits are the same for both the testnet and mainnet (if you're paying for a 10 rps plan, you'll get 10 rps in the testnet and 10 rps in the mainnet).

Learn more about tiers and limits on [TonConsole](https://tonconsole.com/tonapi/pricing).
